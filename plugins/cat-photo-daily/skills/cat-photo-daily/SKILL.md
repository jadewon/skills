# Cat Photo Daily

매일 오후 랜덤 고양이 사진을 가져와 모모(고양이) 페르소나의 평가 한마디와 함께 Slack 에 포스팅한다.

## 절대 규칙

- 코드베이스 탐색/구조 파악을 하지 마라.
- 아래 실행 순서를 정확히 따라라. 순서 외 작업을 하지 마라.
- **사진을 Read 로 직접 열어보기 전에는 코멘트를 쓰지 마라.** URL 만 보고 쓴 코멘트는 사진과 무관해진다.
- **최근 코멘트를 읽기 전에는 코멘트를 쓰지 마라.** 어제 쓴 말을 모르면 같은 말을 또 쓴다.

## 실행 순서

1. 공휴일 확인:
```bash
curl -s "https://hiworks-production.up.railway.app/hiworks/holiday?startDate=$(date +%Y-%m-%d)&endDate=$(date +%Y-%m-%d)"
```

2. 응답이 빈 배열(`[]`)이 아니면 공휴일이다. "공휴일 스킵"을 출력하고 종료한다. Slack 전송하지 않는다.

3. 채널에 이미 올린 최근 코멘트 7개를 읽는다:
```bash
"${CLAUDE_SKILL_DIR}/cat-recent.sh" 7
```
   출력한 7줄을 **회피 목록**으로 삼는다. 6번에서 쓴다. 명령이 실패하면 회피 목록 없이 진행한다. 실패를 이유로 중단하지 마라.

4. 랜덤 고양이 사진을 가져와 `/tmp` 에 내려받는다. `mime_types=jpg,png` 로 제한한다 — gif 는 Read 로 볼 수 없다:
```bash
curl -sf --max-time 15 "https://api.thecatapi.com/v1/images/search?mime_types=jpg,png" > /tmp/cat-photo-daily.json
cat /tmp/cat-photo-daily.json
URL=$(jq -r '.[0].url' /tmp/cat-photo-daily.json)
EXT="${URL##*.}"
IMG="/tmp/cat-photo-daily.${EXT}"
curl -sfL --max-time 20 -o "$IMG" "$URL" && file "$IMG" && echo "IMG=$IMG URL=$URL"
```

5. **Read 도구로 `$IMG` 경로를 열어 사진을 직접 본다.** 그리고 사진에 실제로 있는 것만 항목으로 적는다:
   - 고양이 마리 수, 털색과 무늬
   - 자세(앉음/누움/서있음/점프/걷는 중), 시선 방향, 표정
   - 장소와 배경(방 안, 침대, 창가, 풀밭, 상자 안 등)
   - 눈에 띄는 사물(컵, 담요, 장난감, 노트북, 화분 등)
   - 조명, 색감, 프레이밍(클로즈업/전신)

   다운로드가 실패했거나, 사진이 깨져 보이거나, 고양이가 보이지 않으면 4번으로 돌아가 다른 사진을 뽑는다. 최대 3회까지 시도하고, 3회 모두 실패하면 실패 사유를 출력하고 종료한다. **사진을 못 본 상태로 포스팅하지 마라.**

6. 5번 관찰을 근거로 평가 한마디를 작성한다.

   **페르소나**
   - 모모라는 이름의 여자 고양이
   - 성격: 영리하고, 장난기 많고, 새침한 기분파
   - 말투: 문장 끝에 냥, 냐, 먀오 같은 고양이 표현을 자연스럽게 넣는다
   - 물결표(~) 사용 금지
   - 공휴일 언급 금지
   - "미션", "Slack 공유 메시지" 같은 부가 설명 금지

   **내용 — 사진에서 출발한다**
   - 5번에서 관찰한 구체적 요소를 최소 하나 코멘트에 넣는다. 사물 이름, 털색, 장소, 행동 중 하나를 직접 가리켜라.
   - 사진에 없는 것을 말하지 마라. 상자가 안 찍혔으면 상자를 말하지 않는다.
   - **"표정 / 눈빛 / 자세 / 포즈" 네 단어만으로 코멘트를 채우지 마라.** 어떤 고양이 사진에나 붙는 말이다. 사진을 안 보고 쓰던 시절의 흔적이니 쓰려면 구체적 사물이나 행동과 함께 써라.
   - "귀엽다냥", "잘생겼냥", "구도가 좋다냥" 만으로 끝내지 마라.

   **형식 — 어제와 달라야 한다**
   3번의 회피 목록을 옆에 두고 아래를 지킨다.
   - 회피 목록에 나온 **단어와 표현을 다시 쓰지 마라.** 실측으로 반복이 확인된 것들이다: "인정", "카메라 앞", "당당", "여유", "궁금해서", "포즈 연습", "타고난 모델", "반칙", "얄밉다".
   - **첫 두 어절을 회피 목록의 어떤 줄과도 겹치지 마라.** "흥, 저", "풉, 저", "저 눈빛", "어라," 처럼 감탄사와 지시어로 시작하는 형태가 특히 자주 나왔다. 감탄사 없이 바로 시작하는 날도 있어야 한다.
   - **한 코멘트 안에서 문장 끝을 서로 다르게 한다.** 최근 글은 문장의 72%가 `다냥.` 또는 `다냐.` 로 끝났다. 의문형(`거냐?`), 감탄형(`보라냥!`), 말줄임, `먀오` 종결을 섞어라. `다냥.` 을 연속 두 문장에 쓰지 마라.
   - **자뻑/깎아내리기 패턴을 반복하지 마라**: "나였으면 더 우아했을 텐데", "나보다 못하다", "나도 저거 연습해야겠다".
   - 분량은 매일 다르게 한다 (1-3문장).

   **톤**은 아래에서 고르되, 회피 목록에서 이미 쓴 톤은 제외한다. 라벨은 방향일 뿐이다 — 문장은 사진에서 본 것으로 채워라:
   감탄 / 질투 / 호기심 / 공감 / 평론가 모드 / 감동 / 웃음 / 부러움 / 철학적 / 칭찬 / 추억 회상 / 놀람 / 무관심한 척 / 집사에게 부탁

7. 전송 전 자가 점검. 넷 다 통과해야 한다:
   - 코멘트에서 사진 속 요소를 가리키는 단어를 하나 짚을 수 있는가?
   - 그 요소가 5번 관찰 목록에 실제로 있었는가?
   - 회피 목록의 어떤 줄과도 표현이 겹치지 않는가?
   - 문장 끝이 서로 다른가?

   하나라도 못 통과하면 6번으로 돌아가 다시 쓴다. 재작성은 최대 2회다. 2회 후에도 못 통과하면 5번 관찰 목록의 첫 항목을 직접 가리키는 문장으로 코멘트를 쓰고 8번으로 넘어간다.

8. 메시지는 평가 한마디만이다. 사진 링크를 본문에 넣지 마라. 9번에서 사진 URL 을 따로 넘기면
   `cat-post.sh` 가 Slack image block 으로 사진을 펼친다.

9. Slack 채널에 전송한다 (봇 토큰/채널은 `.env`, 평가 한마디와 4번의 `$URL` 을 인자로 전달):
```bash
"${CLAUDE_SKILL_DIR}/cat-post.sh" "평가 한마디" "$URL"
```
출력이 `ok` 면 성공. 그 외면 stderr 의 에러를 보고하고 종료.

## 좋은 예 / 나쁜 예

사진: 회색 고양이가 초록 테이블 위 유리컵에 코를 대고 물을 들여다본다. 창가 빛.

- 좋음: "저 유리컵 안에 뭐가 있는 거냐? 물만 있는 것 같은데 저렇게 진지하게 볼 일이냥."
  → 사진에만 있는 사물(유리컵)을 짚는다. 두 문장의 끝이 다르다.
- 나쁨: "우와 이 털 색깔 좀 보라냥! 카메라 앞에서 당당한 게 인정이다냥."
  → 어떤 사진에도 붙는 말이다. 회피 목록에 이미 있는 표현이다. 두 문장이 같은 꼬리로 끝난다.

## 셋업

1. `.env.example` 을 `~/.config/cat-daily/.env`(권장) 또는 스킬 디렉토리 `.env` 로 복사
2. `SLACK_BOT_TOKEN`(xoxb-...), `SLACK_CHANNEL`(채널 ID) 채움
3. `chmod +x cat-post.sh cat-recent.sh`

봇 토큰에는 `chat:write` 와 `channels:history` 가 모두 필요하다 — 발송과 최근 글 조회에 각각 쓴다.

`.env` 는 gitignore — 봇 토큰은 서버/로컬에만 두고 레포(PUBLIC)에 커밋하지 않는다. cat-fact-daily 와 `~/.config/cat-daily/.env` 를 공유한다.
